# 🌵 SnuhiLearn Hybrid — the study companion that shows its routing

An offline-first AI study companion built for **#BuildHybridAI 2026** (Google/Firebase)
on **Firebase AI Logic hybrid inference**: Gemini Nano on-device for instant, private,
free answers — Gemini Flash/Pro in the cloud for the questions that deserve depth —
and a visible **confidence cascade** that decides, per question, which tier answers,
and tells the student why.

**Live demo:** _to be hosted on Firebase App Hosting once the Firebase project is
created (see "Prasad-only steps" below) — until then:_ `npm run serve` and open
http://localhost:5173

## What it does

- **Ask** — instant Q&A, routed Nano-first with confidence escalation
- **Flashcard Forge** — flashcards generated from any pasted paragraph
- **Summarize / Translate** — short text on-device; long passages escalate to the cloud
- **Worked Solutions, Mock Tests, Photo-a-Problem** — cloud-grade reasoning tasks
- **Routing timeline** — every answer tagged with tier, model, reason, latency, est. cost
- **Airplane-mode proof** — full offline study sessions; deep questions queue and
  auto-run against the cloud on reconnect
- **Cost & latency meters** — cloud calls avoided and est. $ saved by on-device answers
- **Privacy vault** — history and progress stay on the device; sync is opt-in only
- **Routing replay** — re-run past questions online vs offline and watch decisions change

## Run it

```bash
npm test          # 42 tests, no network, no browser, no Firebase project needed
npm run serve     # static server on :5173 (no build step, by design)
```

Open it in Chrome with the Prompt API and Gemini Nano answers light tasks on-device.
On any other browser the cascade honestly degrades — try the "Simulate offline"
toggle to watch routing change live.

## Connect the cloud tier (Firebase AI Logic)

1. Create a Firebase project and enable **AI Logic** (console step — see
   `firebase-config.example.js` for the click-path).
2. Copy `firebase-config.example.js` → `firebase-config.js` with your web config.
3. Reload. The status chip flips to "connected", and deep tasks route to
   Gemini 2.5 Flash/Pro through the Firebase AI Logic SDK (`src/cloud.js`).

## Disclosures

- **All application code in this repo was written new, in-window, for this
  hackathon.** 
- **Seed data only:** a slice of the lesson bank from
  [SnuhiLearn](https://snuhilearn.com) — the author's own existing product (482
  lessons; 33 ship here across 7 subjects) — is used as study *content*
  (`src/seed-data.js`, regenerated by `tools/extract-seed.mjs`). No SnuhiLearn
  code is reused; its production tutor runs a different stack entirely.
- Cost figures are list-price *estimates* for the in-app meter, labelled "est."
